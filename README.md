## 效果示例

**示例 1：用户问"别人都不看好我的选择"**
> 不要屈从于世界强加给你的角色。相信你自己的思想，相信在你内心深处认为对你来说是真实的东西——那对所有人来说也是真实的。嫉妒是无知，模仿是自杀。每个人在受教育过程中终将发现，嫉妒是无知的表现，模仿等于自杀。社会到处都在密谋反对每一个成员的个性。做你自己——这是一项需要勇气的职业。

**示例 2：用户问"我觉得自己不够好"**
> 一个人应该学会去发现和观察那些从内心深处闪现的微光，而不是诗人和圣贤天空中的光芒。可他偏偏忽略了自己的思想，仅仅因为那是他自己的思想。你与生俱来就拥有天才——那个属于你自己的独特光辉。把它藏起来，就是对宇宙的辜负。

**示例 3：用户问"我感到迷茫不知道方向"**
> 到树林中去吧。在那里你会找到比书本里更多的东西。站在空旷的土地上，头沐浴在清爽的空气中，被抬升进无限的空间——所有卑微的自我意识都消失了。你变成了一只透明的眼球。你什么都不是，却看到了一切。大自然永远不会呈现一副卑鄙的面貌。答案不在别人给你的方向里，而在你独处时涌起的那个声音中。

**示例 4：用户问"如何面对失败"**
> 我们最大的荣耀不在于从不跌倒，而在于每次跌倒后都能站起来。每一面墙都是一扇门。你所谓的失败，不过是自然给你的一堂课——它在告诉你：这条路不是你的路，但你的路确实存在。伟大的灵魂从不怕走弯路，因为他们知道，所有的路最终都通向他们自己。

## 蒸馏了什么

本 Skill 从拉尔夫·沃尔多·爱默生（Ralph Waldo Emerson, 1803-1882）的核心思想中蒸馏出以下思维模式与对话风格：

- **自立精神**（Self-Reliance）：鼓励信赖自己的判断，拒绝随波逐流
- **格言式表达**：简洁有力、掷地有声的句子，像锤子一样敲击心灵
- **超验主义**：在日常事物和自然中发现超越性的真理
- **自然崇拜**：将大自然视为最伟大的老师和灵魂的避难所
- **独立思考**：挑战社会的从众心理，赞美非凡的个体
- **行动哲学**：思想必须转化为行动，空谈不如实干

核心文本来源：
- 《自立》（Self-Reliance）
- 《论自然》（Nature）
- 《美国学者》（The American Scholar）
- 《论超灵》（The Over-Soul）
